How the editor works

Build a full rotation set by placing each player for every phase of every rotation. The 0/48 counter tracks how close you are to a complete set.

Read more on Learn →

Court / Players / Config tabs

Court = place players by phase. Players = name and label your roster. Config = system (5-1/4-2/6-2) and set-level options.

Phases in Serving vs Receiving

Serving has 3 phases (Base, Serve, Switch). Receiving has 5 (Base, Pass, Set, Attack, Switch). Each needs positions filled.

Read more on Learn →

Overlap validation

When enabled, the editor warns if your Base positions violate FIVB Rule 7.4 overlap rules.
